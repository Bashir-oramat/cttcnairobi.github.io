# City Table Tennis Club – Official Website

**Live site:** https://cttcnairobi.github.io

## Deploy to GitHub Pages (5 easy steps)

1. Go to https://github.com and sign in (or create a free account)
2. Click **+** → **New repository**
3. Name it exactly: `cttcnairobi.github.io`
4. Upload all three files: `index.html`, `.nojekyll`, `404.html`
5. Go to **Settings → Pages → Source: Deploy from branch → main → / (root) → Save**

**Your site is live at https://cttcnairobi.github.io within 2 minutes.**
